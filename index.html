CASE STUDY

Zegema Beach Records

Rebuilding an independent record label's website while honoring its DIY roots.

Redesign & build by Erica Shultz, with Claude Code · 2026
THE CONTEXT

A real store, run by one person for over a decade

Zegema Beach Records is an independent record label based in Ladysmith, British Columbia. The quantity and quality of their output have both outgrown their current Squarespace template and deserve to be showcased on a bespoke, user-friendly website, allowing fans to buy merchandise or see what the label and its associated bands are up to.

We'll walk through the old site, the process of building a prototype with Claude Code, and how I re-skinned the existing Squarespace site with custom code.

PART THREE

Making it real

Same design. Real checkout, real inventory, real customers.

THE DECISION

Skin the store, don't replace it

Keep the existing site and layer the redesign on top of it. Squarespace keeps doing what it's good at (payments, inventory, the editor, the domain) and three layers of custom code bring the new site to life. Nothing changes for the site owner, everything changes for the user.

LAYER 1 · THE SKIN

Custom CSS

zbr-custom.css · ~120 KB · 1,022 lines

Restyles Squarespace's own templates: header, nav, product pages, cart, search, contact and news.

LAYER 2 · THE BRAIN

Footer script

footer-code.html · ~70 KB · 1,094 lines

Rearranges what the template renders: news cards, numbered pages, Bandcamp players, back links, the pop-up.

LAYER 3 · THE PAGES

Code Blocks

5 pages · store grid, news sidebar, archives, guestbook, mailing list

New pages built from native Squarespace blocks, created as Not Linked and added to the menu last.

The one rule: nothing is renamed or deleted. Product URLs, orders and analytics carry straight on.
THE SKIN

Working within Squarespace’s confines

Custom code overrides templated product, cart, search and contact pages.

1

Product page. Price, option menu, quantity and Add to Cart share one row. The Bandcamp player is inserted by the footer script where the template had a plain "Listen here" link.

2

Cart. One line per item (name left; quantity, price and Remove right), the subtotal bar unpinned from the bottom, a padlock on Checkout.

3

Two-column news page. On desktop, the news feed sits beside a sidebar of Quick Links, Reviews and Features instead of the template's single column.

4

Cart badge. The template's floating cart pill is hidden and replaced by a View Cart button in the nav with a live item count.

REFINEMENTS

Better than the prototype

Moving to Squarespace meant rethinking details of the Vercel design. Many of the changes made the site easier to use, especially on mobile.

1

"Back" works anywhere. "Back to Store" became a plain "« Back" that returns to the page you came from, so it can be used on any page.

2

Pagination that scales. Numbered pages built to handle 500+ pages of news, with arrows that slide the set of numbers.

3

One guestbook page. Viewing and signing happen on a single page. Partly for ease and partly a Squarespace requirement, but a happy coincidence for visitors.

4

An empty cart has a way out. A button takes shoppers back to the store instead of leaving them at a dead end.

5

Filters grouped on mobile. The three collapsed filter menus sit together so more of the product grid is visible.

6

Quick Links at both ends. On mobile the bar also sits under the pagination, easy to reach from the top and the bottom of the page.

7

"View Cart" after adding. On mobile, a View Cart button appears once a product has been added.

8

Shareable store links. Filters live in the address, so a pre-filtered view like ?cat=sticker can be linked directly.

NATIVE PLUMBING

Fun features, on Squarespace's own rails

The guestbook and the mailing list could have been faked in the front end. Instead each one is a real Squarespace feature wearing the redesign, so the data lands where the label already looks for it.

GUESTBOOK

A Blog page with one post. Entries are its comments, with approval required, so moderation is Squarespace's existing Manage Comments queue. The CSS and script turn comment threads into guestbook entries.

MAILING LIST

A hidden page holding a native Newsletter block, shown inside a pop-up frame so visitors never leave the page. Sign-ups go straight to the list the label already has, and a custom thank-you replaces the template's form.
